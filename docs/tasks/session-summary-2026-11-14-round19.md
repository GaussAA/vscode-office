#### 2. React 内存优化 Hooks

**文件**: `src/react/hooks/useMemoryOptimization.ts`（~120 行）

**useAutoCleanupTimer**:

- 自动清理的定时器
- 组件卸载时自动清除
- 支持 setTimeout/setInterval
- 防止定时器泄漏

```typescript
const timer = useAutoCleanupTimer();

useEffect(() => {
  timer.setTimeout(() => {
    // 组件卸载时自动清理
  }, 1000);
}, []);
```

**useAutoCleanupEventListener**:

- 自动清理的事件监听器
- 组件卸载时自动移除
- 支持多个监听器
- 防止事件监听器泄漏

```typescript
const addEventListener = useAutoCleanupEventListener();

useEffect(() => {
  addEventListener(window, "resize", handleResize);
  // 组件卸载时自动清理
}, []);
```

**useMemoryMonitor**:

- 开发模式的内存监控
- 组件挂载/卸载时记录内存
- 检测组件级别的内存泄漏
- 仅在开发环境启用

```typescript
useMemoryMonitor("MyComponent");
// 自动记录内存使用和变化
```
