## 技术亮点

### 1. 高效的 LRU 实现

**时间复杂度**:

- Get: O(1)
- Set: O(1)
- Delete: O(1)

**空间复杂度**: O(capacity)

**设计优点**:

- 使用 Map 保持插入顺序
- 简单的删除-重插策略更新顺序
- 无需额外的双向链表

### 2. 智能的缓存键设计

**Parquet 单元格缓存键**:

```typescript
key = `${row}:${column}:${valueHash}`;
```

**优势**:

- 精确区分每个单元格
- 使用哈希避免键过长
- 支持任意复杂的值类型

### 3. 自动过期管理

**TTL 特性**:

- 自动检测过期条目
- get 操作时更新时间戳
- 手动 prune 清理过期条目

**应用价值**:

- 防止内存无限增长
- 适应动态数据场景
- 可配置的过期策略

### 4. 完整的监控能力

**统计信息**:

- 命中率（hit rate）
- 命中/未命中次数
- 当前大小/容量

**价值**:

- 评估缓存效果
- 调优缓存策略
- 监控内存使用
