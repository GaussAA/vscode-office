## 📖 如何使用归档文档

### 查找特定改进细节

如果需要了解某个具体改进是如何实现的：

1. 查看主文档 [FINAL-REPORT.md](../FINAL-REPORT.md) 确定是哪一轮

如果需要理解为什么做某个决策：

1. 先查看 [ADR 目录](../adr/) 中的架构决策
2. 再查看相关轮次的会话总结
