#### 1. 为关键组件添加 React.memo

**ParquetCell 组件优化** (`src/react/view/parquet/parquetCell.tsx`)

- 添加 React.memo 包装
- 实现自定义比较函数
- 仅在以下情况重新渲染：
  - value 变化
  - pageIndex 变化
  - position 变化
  - query 变化
  - rowIndex 变化
  - column 变化
- 跳过 onActivate 比较（总是新函数，不影响渲染）

**影响分析**:

- ParquetCell 是每个可见单元格都会渲染的组件
- 大表格可能有数百个实例
- memo 防止父组件状态变化但单元格 props 不变时的不必要渲染
- **预期提升**: 20-30% 渲染性能

**ParquetMetaBar 组件优化** (`src/react/view/parquet/ParquetMetaBar.tsx`)

- 添加 React.memo 包装
- 使用默认浅比较
- 初始加载后很少变化

**影响分析**:

- 防止父组件更新时的不必要渲染
- 元数据通常在文件加载后保持不变
