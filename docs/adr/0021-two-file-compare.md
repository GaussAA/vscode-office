# ADR-0021 两文件对比是命令式的元数据检查面

- 状态：已接受（2026-11-12，方向已定；实现待做）
- 日期：2026-11-12

## 背景

[ADR-0020](./0020-column-profile-direction.md) 把下一步写成「两文件对比」，并要求它自己写一份
ADR：它引入一个新的打开单位（两份文档）和一个新问题（差异），两件事都碰边界。

约束与事实：

- **格式集合已关闭**（ADR-0015），「一个文件一个 viewer」是 PRODUCT 的硬约束。对比因此不能注册
  文件关联，也不能接管双击。[ADR-0019](./0019-json-preview-command.md) 已经给过同类先例：JSON
  预览是 Command preview，不写 `contributes.customEditors`、不注册 `.json`。
- 维护者的真实问题是「上期与本期」：管线每天产出 parquet，要回答的是 **schema 有没有漂移、行数
  有没有突变、某列的空值率有没有暴涨**。这些问题用元数据与 row-group statistics 就能回答
  （ADR-0020 已经把这条接缝做好），不需要解码。
- **行级对比**（「哪些行变了」）需要行身份。这些文件没有主键；按行号对齐，在文件追加或重排之后
  会给出「全都变了」这种假结论；按值对齐则要解码两边并定义匹配规则。这不属于这一批。

## 决定

1. **形态**：Command preview。命令面板里先后选两个 `.parquet`，打开一个只读 webview 面板；
   不注册 customEditors、不改默认编辑器、不新增 viewType，产品名不变。
2. **深度**：只比元数据与画像——schema、行数与行组数、每列的 null 率、区间、基数与状态
   （available / partial / missing / nested）。**不解码任何一列**，也不提供样例行。
3. **schema 不一致**：按顶层列名取并集。只在一侧出现的列标 `added` / `removed`；共有列才比统计；
   两侧类型不同的列单独标 `type changed`——类型不同时区间比较没有意义。
4. **体积**：不设新上限。两侧各读一次 footer 与画像（每侧 ≤ 256 KB 量级），377 MB × 2 也是毫秒
   级；现有 size guard 是为「整份载入」设的，与这里无关。
5. **呈现**：一张表，行＝列，列＝`类型 / 左 null% / 右 null% / 差异 / 状态`。差异只用数字与底色，
   不引入新图形语言。提供「只看有变化的列」开关，并按 `added` / `removed` / `changed` / `same`
   分组。
6. **失败与「不同」要分清**：任一侧打不开或不是 parquet，是错误；两侧**行数不同不是错误**，它是
   结论本身，必须在顶部作为一条事实出现。

## Considered Options

- **行级 diff**：能回答「哪些行变了」，但没有主键时按行号对齐会撒谎（追加一行就让全表「变了」）。
  否决，留作将来独立的 ADR，前提是先有行身份的定义。
- **第四个 viewer**：VS Code 的一个编辑器只承载一个文档，多文件对比的自然形态是面板而不是
  editor；且直接违反 ADR-0015。
- **资源管理器多选右键**：更顺手，但多选语义在各宿主版本上不一致，也与 ADR-0019 的命令式先例
  不同。将来可以在命令之上加一个菜单项，命令仍然是地基。
- **「当前文件 + 再选一个」**：对比没有基准方与对比方之分，这个模型会逼用户先想「谁是基准」，
  而左右本身是不对称的信息（哪边是本期），只能由选择顺序决定。

## 后果

- 新增一个命令、一个 webview panel 入口与 `main.tsx` 的 `case "compare"`；`contributes.customEditors`
  不变。
- 宿主侧复用 ADR-0020 的 `readParquetProfile`：对比 = 两个 profile 的纯函数聚合（并集、状态、
  差异），因此可以在 `test/unit` 里直接测，不需要浏览器。
- 需要一条性能闸门：两侧各 4.3 MB 的 fixture 上完成对比 ≤ 300 ms，且**读出的字节数仍停留在
  footer 量级**（沿用 ADR-0020 的「断言字节而不是耗时」）。
- `verify:ui` 需要新场景：同 schema、列增删、类型变化、一侧打不开、行数不同。
- 不做：行级 diff、导出差异报告、三方对比、把对比结果写回任何文件。
