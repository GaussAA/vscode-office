### 新架构特点

**状态管理集中化**:

```typescript
// 之前：多个 useState 分散
const [loading, setLoading] = useState(false);
const [error, setError] = useState<string | null>(null);
// ... 20+ 个独立状态

// 之后：统一 reducer
const [state, dispatch] = useReducer(parquetReducer, initialState);
```

**逻辑模块化**:

- `parquetReducer`: 纯函数状态管理
- `useParquetDocument`: 文档加载和数据处理
- `useParquetSelection`: 选择和导航逻辑
- `useParquetKeyboard`: 键盘交互
- `useParquetCopy`: 复制功能

### 关键模式

**模式 1: 错误处理辅助函数**

```typescript
const getErrorMessage = (error: unknown): string => {
  if (error instanceof Error) return error.message;
  if (typeof error === "string") return error;
  return String(error);
};
```

应用于 useExcelSave.tsx，100% 消除断言。

**模式 2: instanceof 守卫**

```typescript
if (!(target instanceof HTMLElement)) return;
```

应用于 Parquet.tsx，100% 消除断言。

**模式 3: 安全回退**

```typescript
const bytes =
  raw instanceof Uint8Array
    ? raw
    : raw instanceof ArrayBuffer
      ? new Uint8Array(raw)
      : isObject(raw) && hasProperty(raw, "buffer")
        ? new Uint8Array(raw.buffer)
        : new Uint8Array(0); // 安全回退
```

防止意外类型导致的崩溃。
