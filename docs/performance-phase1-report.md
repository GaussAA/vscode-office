## 💡 优化原则

### 何时添加 memo

1. **纯展示组件** ✅
   - ParquetCell, ParquetMetaBar

2. **频繁渲染的组件** ✅
   - ParquetCell（表格单元格）

3. **渲染成本高的组件** ✅
   - ParquetInspector（检查面板）

4. **状态变化少的组件** ✅
   - ParquetErrorPane, ParquetMetaBar

### 何时不添加 memo

1. **Props 经常变化** ❌
   - ParquetPager（分页状态）

2. **有复杂内部状态** ❌
   - ParquetSchema（过滤和光标）

3. **有交互和 ref** ❌
   - ParquetTopBar（搜索和输入）

## 📝 经验总结

### 成功经验

1. **测试先行**: 建立基准测试确保优化有据可查
2. **文档同步**: 边优化边记录，知识沉淀完整
3. **渐进优化**: 小步快跑，每次改进可验证
4. **决策清晰**: 明确何时用 memo，避免过度优化

### 注意事项

1. **不是所有组件都需要 memo**: 频繁更新的组件反而会增加开销
2. **自定义比较需谨慎**: 只在必要时使用，比较函数本身有成本
3. **测试覆盖很重要**: 确保优化不破坏功能
4. **文档不可少**: 帮助团队理解优化决策
